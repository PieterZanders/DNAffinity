\paragraph{Feature importance and biological interpretation.}
\begin{itemize}
\item \textbf{No GATA signal.} LRP does not show relevance concentrated on a GATA core, for a simple reason: \texttt{4.txt} contains essentially no GATA signal at count $\geq$10. Its strongest $k$-mers are ETS-class sites (ACTTCCGG/CCGGAAGT, GGAA core), and the models' relevance logos highlight exactly these bases. Either the HT-SELEX library selected an ETS-like binder or the file is mislabelled or contaminated. This should be verified against the original SELEX run before any Gata4-specific interpretation.
\item \textbf{Shape vs.\ sequence.} CNN1D uses one-hot most, yet it still gives about half of its relevance to shape channels in set (a). Because the shape values are a deterministic function of the 16 one-hot channels of the same window, the network can spread the same information over both, and LRP shares the credit between them. This is consistent with the identical accuracy of sets (a) and (d). The DFN, which has no positional weight sharing, leans on the stiffness terms.
\item \textbf{Which shape parameters.} The most relevant terms are couplings involving TILT, ROLL, SLIDE and TWIST (TILT--ROLL, SLIDE--TILT, ROLL--TWIST) and the RISE and SHIFT stiffnesses. RISE has the clearest positive effect on strong binders. Roll/twist/slide deformability is a plausible indirect-readout signal for an ETS-type GGAA site, which is recognised in the major groove with DNA bending.
\item \textbf{Caveats.} LRP maps for the CNN depend on the rule choice: $\gamma$ maps correlate only 0.14--0.17 with gradient$\times$input, and only about 50\% of the output is conserved. Feature-type shares are partly driven by the number of channels per group. The positional profiles mainly reflect architecture (padding for CNN1D, window coverage for the DFN).
\end{itemize}
