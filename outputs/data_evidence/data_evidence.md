# Data evidence: uPBM label noise and SELEX "Gata4" identity

Generated by `scripts/data_evidence.py` (key numbers are in `key_numbers.json`). The overview figure is `summary_data_evidence.png`.

## uPBM Gata4 (`data/upbm/Gata4/Gata4_training.txt`)
| plot / table | finding | conclusion |
|---|---|---|
| `upbm_1_duplicate_pair_scatter.png`, `upbm_duplicate_pair_correlations.csv` | There are 577 pairs of the same 10-mer: 558 exact duplicates and 19 reverse-complement (RC) pairs. Their labels correlate at only **Pearson r = 0.43 and Spearman ρ = 0.49**. The RC pairs alone show r ≈ 0 (n = 19). None of the pairs have identical values, so these are independent probes and not copies made by oversampling. | When the same sequence is measured twice, the two labels agree only weakly. Most of the label variance is probe context and noise, not the 10-mer itself. |
| `upbm_2_duplicate_spread_hist.png`, `upbm_duplicate_summary.csv` | 575 duplicated canonical sequences. The median within-sequence range is **0.072**, against a median label of 0.111. 186 groups have a range larger than the median label, and the spread grows with the mean. | Duplicate labels must be aggregated (now done) and must never be split across train and test (old pipeline: 100% leakage). |
| `upbm_3_label_distribution_artifacts.png` | There are 5,510 distinct values in 5,511 rows, so **there is no discretisation and no copied labels**. The distribution is right-skewed (skew 1.49) with a long upper tail from bin undersampling. 24 values are below 1e-3, and 1 sits at the min-max cap of 1.0. | The preprocessing artifacts are the shape of the distribution (undersampled bulk, extreme tail) and the duplicates, not quantisation. My earlier guess of "oversampling copies" is **not** supported by the data. |
| `upbm_4_noise_ceiling_vs_models.png` | Single-measurement reliability is r = 0.426, with 1.12 copies per sequence on average. The Spearman–Brown reliability of the aggregated label is 0.453, which gives a **ceiling of about r = 0.67 (ρ = 0.72)** for a perfect predictor. All 41 uPBM CV runs fall between Pearson 0.605 and 0.642. | Every model, from linear regression to the Transformer, is within about 0.03–0.07 of the noise ceiling. On this dataset, better deep models cannot show a meaningful gain. Better or replicated labels are needed. |

## SELEX "Gata4" (`data/selex/Gata4/4.txt`, cycle 4)
| plot / table | finding | conclusion |
|---|---|---|
| `selex_1_top_kmers_table.png`, `selex_top30_kmers.csv` | The top k-mers (count ≥ 10) are ACTTCCGGTC (count 810, affinity 1.00), GACTTCCGGT, TTCCGGCGGA, CACTTCCGGT and so on. The TTCCGG core (CCGGAA on the other strand) is in 8 of the top 10. **None of the top 10 contain WGATAR.** | The strongest binders are ETS-family sites (GGAA core), not GATA sites. |
| `selex_2_logo_top_kmers_vs_gata.png`, `selex_top200_TTCCGG_aligned_counts.csv` | 68% of the top-200 k-mers contain TTCCGG. Aligned on it, they give a clear **(A)CTTCCGG(T)** logo, the classic ETS class I site. **0% of the top 200 contain WGATAR.** The GATA4 reference logo is shown for comparison. | The motif learned from this file is ETS, not GATA4. |
| `selex_3_gata_vs_ets_enrichment.png`, `selex_motif_enrichment.csv` | CCGGAA k-mers make up 1.9% of all k-mers, but **70% of the top 100 (37.7× enrichment) and 46% of the top 1000 (24.7×)**. WGATAR k-mers make up 0.6% of all k-mers and **0% of the top 100 and top 1000**. The bare GATA core is depleted (0.76× in the top 100, 0.55× in the top 1000). Mean affinity is 0.43 for CCGGAA k-mers and 0.22 for WGATAR k-mers, about the same as the 0.23 average for k-mers without WGATAR. | The file is not a GATA4 enrichment. It is most likely an ETS-factor experiment (or a mislabelled file or contaminated library). Check the sample ID and source before using it for Gata4. |
| `selex_4_selex_test_is_upbm.png`, `selex_test_vs_upbm_identity.csv` | `SELEX_test.txt` and the uPBM training file both have 5,511 rows and identical label quantiles (median 0.110682 in both; KS D = 0.0002, p = 1.0). They share 2,521 exact 10-mers, whose labels correlate at r = 0.962, and 81% of those labels are bit-identical. They use the same WEIGHT scheme (1/10). Only 8.5% of the `SELEX_test.txt` sequences appear in the SELEX `4.txt` k-mer table. | `SELEX_test.txt` is a (re-sampled) copy of the uPBM data, not a SELEX test set. Remove or rename it. |
